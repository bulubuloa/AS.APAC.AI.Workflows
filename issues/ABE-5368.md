## 3. Blockers / decisions needed

**B1 — No Benefit API returns tier or customer attributes by job id.** The only RSA→Benefit batch lookup is `POST api/webhook-roadside/customerredeemedprivilege/query-by-roadside-job-ids`, which returns tax payment dates only. Needs a new endpoint. This is almost certainly Jessie's "split into 2 US".
Side note: the existing endpoint returns **404 when nothing matches** — the new one must return an empty list instead, or AC §2 (header-only file when no records) breaks.

**B2 — Porsche client has none of the 6 attribute Field Codes configured.** `client_customer_field_config` for PTH (SIT `ClientID=678`, UAT `555`) holds only the default set plus a junk `test` field. `BType` exists for **no client in either environment**. Without config + data, columns F, G, I, K, L, M export blank for every row.

**B3 — Tier values don't match the template.** PTH tiers on SIT are `gold`, `silver`, `Porsche RSA Tier`, `POR CS Tier`. The template expects `New Vehicle` / `Pre-owned` / `Non Member` / `Used 1 Year` (Report sheet sample says "Used 1 Year", Sheet1 says the other three — the template contradicts itself). Need the authoritative list, and whether Report Type is the raw tier name or a mapping.

**B4 — Template note vs sample conflicts** (note wins? sample wins?):
- Dates: notes say `DD/MM/YYYY`; samples show `20250625` (YYYYMMDD) for Incident/Registration Date and `2020-12-12 00:00:00` for Policy Start/End.
- Country: notes say hardcode `TH`; samples show `VN`. (Porsche is Thailand → `TH` presumed.)
- Carried Out By: notes say hardcode `Aspire`; samples show `Porsche` / `John Doe`.
- Time Of Completion: "only minutes, round" *and* "up to 2 digits after decimal point".

**B5 — Towing Distance: recompute or reuse?** `JobInfoExtra.towingKm` and `linearCmToReach` already exist and are already in the CSV. AC says compute from lat/long "per the job map logic". Confirm which. Coverage on SIT is thin: 237/1191 jobs have both coordinates, 168 have `towingKm`.

**B6 — Two cancel statuses.** RSA has `CMCANCEL` (3) and `PVCANCEL` (4); AC's RSA Successful rule names only "Cancel". Assuming both → blank.

**B7 — 18 of 49 columns are constant blanks.** Worth confirming with Jessie this is intended and not an unfinished mapping.

**B8 — Component depends on ABE-4681 defect-issue seed.** Only 40/1191 SIT jobs have `defectIssue` populated.
