# apac-booking-modernization-backend (ABMB) — RSA / RoadSide

- Source: `RoadSide/bkkrsa2020-master/` (`BkkIsos47.sln`) — .NET Framework 4.8 ASP.NET MVC/WebAPI on IIS. Projects that ship: `BkkRsa` (agent portal "MSU", provider portal, partner/Benefit webhooks) and `BkkRsaPartner`; Compass is not deployed. MSSQL `BKKRsa`.
- Branches → pipelines: `roadside_release_sit` (underscores) → `roadside-backend-sit`; `roadside-release-uat` → `roadside-backend-uat`; `roadside-release-preprod`; `roadside-release-production` → deploy only on tag `prod/YYYYMMDD_NN` + manual approval. Release branches `release/uat/ABE-…`, `release/prod/release-<date>`; DB scripts under `RoadSide/bkkrsa2020-master/DatabaseScript/<Release>/` with `RUN-ORDER.md`.
- Windows CodeBuild is in `us-east-1`; buildspec/appspec/`aws/codedeploy/*.ps1` live on the env branch. `Web.config` is gitignored — real config stays on the server; SSM Parameter Store injects `BenefitWebHookEndPoint` etc.
- Benefit data (privileges, programs, redemptions, providers/dealers) comes from ABCB (`api/clients/*`, `api/webhook-roadside/*`) and ABVB (vendor/dealer sync). Provider rows in `cloud.UserAccount` carry `vendorCmsId`; the Ver2 sync writes dispName/userName/mobile/active/group/note and, since ABE-5457, `isProviderMobile`. Do not read provider attributes only from the CMS — dispatch SQL joins the RSA table (touchpoint audit in memory `abe-5457-provider-mobile-flag`).
- Vehicle brands/models/engine systems/defect issues are Kontent.ai content types (prod env `994226e6…`, SIT/UAT `225b0999…`); `BrandCmsService` defaults to **prod** when `KontentEnvironmentId` is missing from Web.config.
- Verify on UAT: `roadside-uat.aspireasia.net` (agent portal), Playwright e2e suite in `RoadSide/bkkrsa2020-master/QA/e2e` (449 cases; `npm ci`, `.env` with BASE_URL + admin account). RSA UAT/preprod MSSQL is on `apac-staging`, stopped nightly ~20:00 Bangkok.
- Stored procedures drift between UAT and prod (announcement SPs incident, memory `abmb-roadside-announcement-sp-drift`): diff `SHOW CREATE` before touching one; the repo script for ABE-4470 is guarded.
- Job ids are strings like `26JB067586`; `JobInfo.brand` was widened to 255 on UAT (prod SQL pending). Honda = client 380, Benz = 338 for Benefit redemption validation.
