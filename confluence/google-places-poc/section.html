Request flow — CMS vs Google

Every call the CMS vs Google tab makes, in order. {app} = the POC host (Lambda Function URL), which adds the Google key — the browser never sees it. {env} = Kontent environment: UAT 225b0999-fce9-02b4-c44b-ed6990faeeaa, PROD 994226e6-d1a5-023e-0fc9-21571d884f47. Nothing is written to Kontent.
